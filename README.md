# 💾 Repositório: Banco de Dados

## 📚 Sobre o Projeto

Este diretório faz parte do repositório é dedicado aos trabalhos, exercícios e projetos práticos da disciplina de **Banco de Dados**.

O principal objetivo é demonstrar a aplicação de conceitos de modelagem e manipulação de dados em um Sistema de Gerenciamento de Banco de Dados (SGBD).

## ✨ Objetivos de Aprendizado

Os arquivos contidos aqui abordam tipicamente os seguintes objetivos:

1.  **Modelagem de Dados:** Criação de diagramas de Entidade-Relacionamento (ER) ou UML.
2.  **Normalização:** Aplicação das formas normais (1FN, 2FN, 3FN) para garantir a integridade dos dados.
3.  **Definição de Dados (DDL):** Criação da estrutura do banco de dados (tabelas, chaves, índices) utilizando SQL.
4.  **Manipulação de Dados (DML):** Inserção, consulta, atualização e exclusão de dados (comandos `SELECT`, `INSERT`, `UPDATE`, `DELETE`).
